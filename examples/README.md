# Examples

Two small, copy-pasteable examples. They are documentation only; the plugin
does not read this directory at runtime.

- [`cordis.patch.example.yml`](cordis.patch.example.yml) — a profile patch that
  sets an explicit model and tight budgets.
- [`prompts.md`](prompts.md) — rough prompts that demonstrate the intended
  question flow.

To try a prompt, open a DSH session and send:

```text
/enhance <one of the rough prompts>
```

Then answer the panel questions and press **Insert**.
